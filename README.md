# Parkinson's Disease Classification using k-Nearest Neighbors (k-NN)

This project applies the **k-Nearest Neighbors (k-NN)** algorithm to classify patients as either having **Parkinson's disease** or being healthy, based on biomedical voice measurements. The analysis includes data preprocessing, model training, evaluation, and visualization to better understand the dataset and assess the performance of the model.

## Features
- Data cleaning and feature scaling for optimal model performance
- Implementation of the k-NN classifier with adjustable hyperparameters
- Model evaluation using accuracy, confusion matrix, and classification report
- Visualizations to explore the dataset and decision boundaries

## Results
The project demonstrates how k-NN can be applied to medical data classification, achieving solid predictive performance and providing clear visual insights into the separation of patients with and without Parkinson's disease.
